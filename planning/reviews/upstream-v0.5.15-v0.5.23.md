# 上游更新审阅：v0.5.15 → v0.5.23

**结论：这 80 个提交已经在本地 `main` 的历史中，不需要逐个挑取，也不需要再合并一次。** 远端 fork 尚未追平。产品上，直接沿用上游的会话压缩、CodeMirror 和团队协作；fork 的第一项投入应是升级回归测试，第一项差异化候选是 Rust 项目记忆，而不是重写编辑器或再造执行器。实施仍待维护者确认，见 [演进规划](../../ROADMAP.md)。

## 核对口径

- 本地 Git 快照，2026-11-21。左端 `origin/main` = `69149068`（v0.5.15，不含），右端 `upstream/main` = `7aa2bedd`（v0.5.23，含）。本地 `HEAD` = `5f8cde66`；`397af379` 和 `5f8cde66` 是 fork 的两个本地提交，不算作上游更新。
- 三个子代理分段核对提交及改动文件，主审按**真实标签指向的提交**重新分组，与[中文发行说明](../../RELEASE_NOTES_ZH.md)、迁移源码和发布工作流交叉核对。下表覆盖所有提交；没有把每个文件的每一行都当作审计对象，也没有运行应用、升级真实数据库或验证发布产物。
- 区间共 **80 个提交，0 个合并**。两端按 `git diff -M` 净比较：**939 个文件，+45,303 / −16,669 行**；125 新增、22 删除、344 修改、448 重命名。中间夹有 Rust 工作区拆分，不能把这个数字当作新增功能量。

## 影响决策的六个边界

| 主题 | 代码证据与实际边界 | 下一步如何验收 |
| --- | --- | --- |
| 工具名不是权限 | `8ddc4582`、`11e623ab`：旧配置和旧终端授权**不迁移**。`config-manage` 的只读动作与写动作不同；终端只读动作共用工具授权，写动作分别授权。旧卡片可显示，不代表旧名仍可调用。浏览器和桌面工具也已合并。见[动作授权策略](../../src/renderer/components/mainContent/chatMessages/utils/toolActionPolicy.ts)。 | 用旧许可、旧禁用项、Hook 和子代理工具列表做升级夹具；逐项复核新动作，不以整组放行代替迁移。 |
| 会话上下文 ≠ 项目记忆 | `f7688f47` 的 `context-recall` 只能回看当前会话；`a001e461` 加的是后台压缩调度。`ba8ec96a` 改已有记忆的 `directory_id`，不改记录 ID。[记忆检索](../../native/crates/snow-storage/src/project_memories.rs)仍要求文本命中；[注入入口](../../native/crates/snow-tools/src/servers/memory.rs)优先返回已冻结的会话快照。 | 分别验证同会话原文回溯、跨会话检索和项目隔离。项目 A → 全局 → 项目 B 只改变可见域；新排序不重写已开会话前缀。 |
| 迁移与生命周期 | `14b7ce6c` 的 v70 是敏感命令反馈表；`debaf820` 的 v71 是全局 MCP 配置的 `oauth` 位，默认 0，不是 embedding 列；项目级旧 JSON 缺字段按关闭处理。`.22` 的单删导出与批量删除分开实现。[迁移](../../native/crates/snow-storage/src/migrations.rs)；[单删导出](../../native/crates/snow-exports/src/storage_exports/conversations.rs)。 | 空库、v69、v70 升至 v71；保住旧授权、旧记忆和外键关系。删除会话默认保留记忆，只有勾选时才连删；与按 `response_id` 回滚分开测试。 |

| 运行可靠性 | `7b8fb099` 去掉固定轮数/子代理部分预算，不代表耗用无限制也安全。Team 媒体、重连与投票已实现，但“旧评审导入转换”不等于已有 SQLite 记录都被重写。R2 [任务日志](../../native/crates/snow-storage-services/src/services/backup/journal.rs)支持按块续跑，不是全应用通用队列，也不是逐字节续传。 | 验旧 Team 媒体引用与评审数据；为子代理设并发边界和人工停止点。用样本库/隔离存储做实际还原，不能拿 R2 列举成功当作恢复通过。 |
| 编辑器与发布 | `11e15a92`、`fd645901` 分别落地[编辑态](../../src/renderer/components/rightPanel/fileViewer/CodeEditor.tsx)和[只读态](../../src/renderer/components/rightPanel/fileViewer/CodeViewer.tsx)，并非整套 IDE。`8af95905` 移除的是上游 Intel Mac **发布任务**，不是证明源码不能在该架构构建。[工作流](../../.github/workflows/release.yml)仍监听 `v*` 标签和手工发布。 | A 先验证两态的搜索、折叠、审阅差异，按需要补只读诊断；不换内核。以后同步历史标签前单独核对 fork 的 Actions 状态与标签冲突；标签不附带 Release 和二进制。 |
